## 3. ปัญหาที่เจอและวิธีแก้

### ปัญหา 1: shell ของ agent เรียกเครือข่ายไม่ได้

- **อาการ:** `getaddrinfo failed` / ก่อนหน้านี้พบ `WinError 10013` ขณะทดสอบ localhost
- **สาเหตุ:** ข้อจำกัดของบริบทการรันในสภาพแวดล้อม agent; ไม่ได้พิสูจน์รายละเอียดกลไกระดับระบบปฏิบัติการ
- **วิธีแก้:** ตรวจ endpoint ที่ได้รับอนุญาตผ่านเบราว์เซอร์และดู JSON จาก server ที่ผู้ใช้เปิดอยู่ แยกผลนี้ออกจากการทดสอบ unit
- **สถานะ:** ยืนยันเป้าหมายการดึงจริงผ่านแอปสำเร็จ; ไม่ได้เปลี่ยนหรือปลดข้อจำกัดเครือข่ายของ shell

### ปัญหา 2: commit ไม่ได้

- **อาการ:** `fatal: Unable to create 'C:/Users/Nattapong/Documents/FloodLens-Starter/FloodLens/.git/index.lock': Permission denied`
- **สาเหตุ:** สิทธิ์ที่ระบุสำหรับ `.git` เป็น read-only ในสภาพแวดล้อมนี้
- **วิธีแก้:** เก็บไฟล์งานไว้และรายงานตรงๆ ไม่เปลี่ยนสิทธิ์ ไม่ลบ lock และไม่พยายามเขียน git ผ่านช่องทางอื่น
- **สถานะ:** ยัง commit ไม่ได้ ไม่มี hash ใหม่ที่จะรายงาน

### ปัญหา 3: ข้อความไทยใน output ของ terminal ดูเหมือนเสีย

- **อาการ:** Get-Content แสดงเครื่องหมาย `?`
- **สาเหตุ:** การเข้ารหัส output ของ console; ไฟล์จริงมีอักษรไทยปกติ
- **วิธีแก้:** ตั้ง `[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new()` เฉพาะการอ่านใน process แล้วอ่าน workflow ได้ครบ
- **สถานะ:** แก้การอ่านแล้ว ไม่แก้เนื้อหา AGENT_WORKFLOW.md ของผู้ใช้

## 4. สิ่งที่ยังค้าง / ข้อจำกัด

- ยังไม่ได้ commit ไฟล์ใดในรอบนี้ จึงไม่สามารถทำให้ git status สะอาดตาม workflow ได้
- `AGENT_WORKFLOW.md` เป็นไฟล์ของผู้ใช้ที่ยังไม่ tracked ตั้งแต่ก่อนเริ่มงาน ไม่ได้แก้เนื้อหา
- `--check-live` ทดสอบสัญญา CLI ด้วย mock; ยังไม่ได้รันคำสั่งใหม่นี้ผ่าน shell ที่เปิดเครือข่ายได้ การยืนยัน live ข้างต้นมาจาก `/api/live` จริงของโค้ด baseline
- ไม่ได้เปลี่ยนตัวเชื่อม API เพราะ response จริงตรงกับ parser เดิมแล้ว ไม่ได้รีสตาร์ต server ของผู้ใช้
- ยังไม่ได้ตรวจ UI ของ footer หลังแก้ในเบราว์เซอร์ ตรวจเนื้อหาไฟล์และ diff แล้ว
- ไม่ได้รับประกันความพร้อมใช้งานระยะยาวของ public feed และไม่ได้เชื่อม SWOC/JWT
- ใช้รัศมี 10 กม. ตามขอบเขตงานก่อนหน้า รวมสถานีใกล้เคียงนอกเขตลาดกระบัง ไม่มีข้อสรุปด้านความเชื่อมโยงทางอุทกวิทยาของทุกสถานี

## 6. วิธีตรวจสอบผลงาน

```powershell
python -m unittest discover -s tests -v
python app.py --check-live
```

- Unit tests ผ่าน 13 ข้อ รวมการแยกข้อมูลขาดหายจากศูนย์ ฝนสะสม 24 ชม. รัศมีสถานี ข้อมูลเก่า และ exit code ของ CLI

- `git diff --check` ผ่านหลังการแก้ไข; ข้อความเตือน LF/CRLF เป็นการตั้งค่า line ending ของ git
